# Wild Australia v17 — larger, more readable takeaways

This version is a copy of v16 with **the same eight charts, chart data, and layout**.

Changes:
- Takeaway paragraph size increased from 13.3 px to 15.5 px.
- Takeaway heading size increased to 17.5 px.
- Takeaway kicker slightly increased to 12 px.
- Text measure limited to 40ch for short, easy-to-read lines (roughly 7–10 words depending on the text and viewport).
- Slightly increased the takeaway box minimum height to comfortably fit the larger text.
- Kept shorter lines on both desktop and mobile layouts.

Open `index.html` with VS Code Live Server.
